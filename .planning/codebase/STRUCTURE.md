## Directory Purposes

**src/components/:**
- Purpose: All React components organized by domain
- Contains: Form dialogs, detail panels, tables, stats cards
- Key subdirectories: `invoices/`, `purchase-orders/`, `draws/`, `jobs/`
- Pattern: Each domain has FormDialog, DetailPanel/Dialog, Table, Stats components

**src/components/ui/:**
- Purpose: shadcn/ui primitive components
- Contains: Button, Card, Dialog, Table, etc.
- Generated by: shadcn CLI
- Do not modify directly

**src/components/layout/:**
- Purpose: App shell and navigation
- Contains: `AppLayout.tsx`, `Sidebar.tsx`, `Header.tsx`, `TopNavigation.tsx`
- Used by: All pages wrap with AppLayout

**src/pages/:**
- Purpose: Route-level page components
- Contains: One file per route (Invoices.tsx, Jobs.tsx, etc.)
- Pattern: Page fetches data, renders components, handles filters

**src/integrations/supabase/:**
- Purpose: Supabase client configuration and generated types
- Contains: `client.ts` (Supabase client), `types.ts` (database types)
- Auto-generated: Types from database schema

**supabase/functions/:**
- Purpose: Deno edge functions for server-side processing
- Contains: AI extraction, PDF stamping, email sending
- Runtime: Deno (TypeScript with Deno imports)
- Each function: `index.ts` entry point

**supabase/migrations/:**
- Purpose: Database schema migrations
- Contains: SQL files with timestamps
- Pattern: `YYYYMMDDHHMMSS_uuid.sql`

## Key File Locations

**Entry Points:**
- `src/App.tsx` - Application entry, routing, providers
- `src/main.tsx` - React DOM render (implied)

**Configuration:**
- `vite.config.ts` - Build configuration, path aliases
- `tsconfig.json` - TypeScript configuration
- `tailwind.config.ts` - Tailwind theme customization
- `vitest.config.ts` - Test configuration

**Core Logic:**
- `src/integrations/supabase/client.ts` - Supabase client
- `src/contexts/JobContext.tsx` - Job selection state
- `src/types/financial.ts` - Financial type definitions

**Edge Functions:**
- `supabase/functions/extract-invoice/index.ts` - AI invoice extraction (~900 lines)
- `supabase/functions/stamp-invoice/index.ts` - PDF stamping (~500 lines)

**Testing:**
- `src/test/setup.ts` - Vitest setup file
- No test files currently exist

## Naming Conventions

**Files:**
- PascalCase.tsx: React components (`InvoiceDetailDialog.tsx`)
- kebab-case.ts: Utilities and types (`financial.ts`)
- index.ts: Barrel exports (`src/components/invoices/index.ts`)

**Directories:**
- kebab-case: All directories (`purchase-orders/`, `daily-logs/`)
- Plural for collections: `components/`, `pages/`, `hooks/`

**Special Patterns:**
- `*FormDialog.tsx`: Modal form for creating/editing
- `*DetailDialog.tsx` or `*DetailPanel.tsx`: Read view with actions
- `*Table.tsx`: List view with sorting/filtering
- `*Stats.tsx`: Summary statistics cards

## Where to Add New Code

**New Feature/Domain:**
- Components: `src/components/{feature-name}/`
- Page: `src/pages/{FeatureName}.tsx`
- Route: Add to `src/App.tsx`
- Types: `src/types/{feature-name}.ts` or extend existing

**New Edge Function:**
- Create: `supabase/functions/{function-name}/index.ts`
- Deploy: via Supabase CLI

**New UI Component:**
- shadcn primitive: Use shadcn CLI to add
- Custom component: `src/components/ui/` or domain folder

**Database Changes:**
- Create migration in `supabase/migrations/`
- Update types in `src/integrations/supabase/types.ts`

## Special Directories

**node_modules/:**
- Purpose: npm dependencies
- Committed: No (in .gitignore)

**dist/:**
- Purpose: Build output
- Generated by: `npm run build`
- Committed: No (in .gitignore)

**.planning/:**
- Purpose: GSD planning documents
- Contains: PROJECT.md, roadmap, codebase docs
- Committed: Yes
