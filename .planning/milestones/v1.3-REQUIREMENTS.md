# Requirements: Ross Built CMS v1.3 (Archived)

**Archived:** 2026-01-18
**Core Value:** Streamline construction financial workflows from bidding through payment

## v1.3 Requirements

Requirements for v1.3 Refinement milestone. Each maps to roadmap phases.

### Invoice AI

- [x] **INV-AI-01**: User sees improved extraction accuracy for invoice amounts, dates, and vendor names via two-stage pipeline
- [x] **INV-AI-02**: User sees smarter auto-matching of invoices to POs and jobs with multi-signal confidence scoring
- [x] **INV-AI-03**: User can approve invoices with fewer clicks through streamlined workflow and batch actions

### Reporting

- [x] **RPT-01**: User can generate financial summary reports (job cost, spend by vendor, spend by category)
- [x] **RPT-02**: User can export any data view to Excel with professional formatting
- [x] **RPT-03**: User can generate printable PDF reports for clients and owners
