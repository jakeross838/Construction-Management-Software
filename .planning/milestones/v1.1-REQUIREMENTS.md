## v1.1 Requirements (All Complete)

### Bids (BID-01 to BID-05)
- [x] BID-01: Bid CRUD - Create, update, delete, list bids with filters
- [x] BID-02: Bid File Upload - Upload bid documents (PDF), storage, preview
- [x] BID-03: Bid Status Workflow - received → under_review → accepted/rejected
- [x] BID-04: Bid Comparison View - Compare multiple bids side-by-side
- [x] BID-05: Convert Bid to PO - Convert accepted bid with scope mapping

### Estimates (EST-01 to EST-05)
- [x] EST-01: Estimate CRUD - Create, update, delete, list estimates
- [x] EST-02: Estimate Line Items - Add by cost code with quantity/unit/total
- [x] EST-03: Import from Bids - Import accepted bid amounts to estimate
- [x] EST-04: Estimate Versions - Version control with comparison
- [x] EST-05: Convert to Budget - Convert approved estimate to budget lines

### Photos (PHO-01 to PHO-04)
- [x] PHO-01: Photo Upload - Drag-drop, multi-select, mobile-friendly
- [x] PHO-02: Photo Metadata - Caption, date, location, category, GPS
- [x] PHO-03: Photo Gallery - Grid view, lightbox, filters, search
- [x] PHO-04: Link to Entities - Link to inspections, punch items, daily logs

### Dashboard (DASH-01 to DASH-02)
- [x] DASH-01: Overview Metrics - Stats bar, real-time updates
- [x] DASH-02: Alerts/Notifications - Upcoming inspections, budget overruns, pending approvals

### UX Polish (UX-02 to UX-03)
- [x] UX-02: Global Search - Cmd/Ctrl+K search across entities, keyboard shortcuts
- [x] UX-03: Mobile Responsiveness - Hamburger menu, scrollable tables, full-screen modals
