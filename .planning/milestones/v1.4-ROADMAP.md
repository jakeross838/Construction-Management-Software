# Milestone v1.4: Price Intelligence

**Status:** SHIPPED 2026-01-18
**Phases:** 24-29
**Total Plans:** 6

## Overview

v1.4 Price Intelligence builds a comprehensive price tracking and order optimization system. Six phases: database foundation, price database backend, order optimizer backend, savings & analytics backend, frontend implementation, and PO integration.

## Phases

### Phase 24: Database Foundation

**Goal**: Create database schema for price intelligence system
**Depends on**: Nothing (first v1.4 phase)
**Plans**: 1 plan

Plans:
- [x] 24-01: Schema Migration

**Details:**
- All v2_* tables for price intelligence exist in database
- Materialized view v2_current_prices returns latest price per item/vendor
- Waste factors seeded with construction category defaults
- Vendor table has delivery/lead time columns

### Phase 25: Price Database Backend

**Goal**: API for master items with vendor price comparison
**Depends on**: Phase 24
**Plans**: 1 plan

Plans:
- [x] 25-01: Price Database API

**Details:**
- User can list/search master items via API
- User can view all vendor prices for a master item
- Prices are normalized to common units ($/each, $/lf, $/sf)
- Confidence scores reflect data quality

### Phase 26: Order Optimizer Backend

**Goal**: Optimization algorithm for material lists
**Depends on**: Phase 25
**Plans**: 1 plan

Plans:
- [x] 26-01: Order Optimizer API

**Details:**
- User can submit material list and get vendor split recommendations
- Waste factors applied by category
- Lead time filtering works when need-by date specified
- Optimization includes delivery fees in total cost
- User can generate POs from optimization results

### Phase 27: Savings & Analytics Backend

**Goal**: APIs for savings tracking and spend analytics
**Depends on**: Phase 25
**Plans**: 1 plan

Plans:
- [x] 27-01: Savings & Analytics API

**Details:**
- User can log savings entries when using optimized orders
- User can view savings by job, category, and time period
- User can view vendor spend breakdown and ranking
- Negotiation insights surface high-spend vendors

### Phase 28: Frontend Implementation

**Goal**: Price Intelligence page with 4 tabs
**Depends on**: Phases 25, 26, 27
**Plans**: 1 plan

Plans:
- [x] 28-01: Frontend Verification

**Details:**
- User can access Price Intelligence from navigation
- Price Database tab shows items with vendor price comparison
- Order Optimizer tab accepts material list and shows recommendations
- Savings Tracker tab shows savings summary and history
- Spend Analytics tab shows vendor spend and negotiation insights

### Phase 29: PO Integration

**Goal**: Better-pricing warnings on PO creation
**Depends on**: Phase 25
**Plans**: 1 plan

Plans:
- [x] 29-01: PO Price Warnings Verification

**Details:**
- Price check API returns better options for PO line items
- Warning banner appears in PO modal when better pricing available
- User can view alternatives without leaving modal
- User can dismiss warnings

---

## Milestone Summary

**Key Decisions:**
- Master items schema with vendor aliases
- Materialized view v2_current_prices for fast lookups
- Price matcher service with Jaro-Winkler-like matching
- Waste factors seeded by construction category
- 10% threshold for price warnings (>10% higher triggers warning)

**Issues Resolved:**
- All v1.4 requirements (PRC-01 through PRC-05) implemented and verified

**Technical Debt Incurred:**
- None significant
