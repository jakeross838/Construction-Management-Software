## v1.6 Requirements

Requirements for v1.6 Module Expansion. All shipped.

### Leads/CRM

- [x] **LED-01**: User can create a lead with contact info (name, email, phone)
- [x] **LED-02**: User can capture project info (type, budget range, timeline, address)
- [x] **LED-03**: User can track lead source (website, referral, phone, etc.)
- [x] **LED-04**: User can view leads in a filterable list by stage and source
- [x] **LED-05**: User can move leads through 7-stage pipeline (Inquiry → Qualification → Consultation → Design Agreement → Proposal → Contract → Won/Lost)
- [x] **LED-06**: User can score leads using qualification criteria (budget, timeline, scope, decision-ready, location)
- [x] **LED-07**: User can create follow-up tasks with due dates for a lead
- [x] **LED-08**: User can log activities on a lead (calls, emails, meetings, site visits, notes)
- [x] **LED-09**: User can mark a lead as Won and convert it to a Job (data transfers automatically)
- [x] **LED-10**: User can mark a lead as Lost with a reason (budget, timing, competitor, etc.)
- [x] **LED-11**: User can view stage history for a lead (when moved between stages)
- [x] **LED-12**: User can attach documents to a lead (plans, inspiration, contracts)

### Selections/Allowances

- [x] **SEL-01**: User can create selection categories (flooring, fixtures, appliances, etc.)
- [x] **SEL-02**: User can create allowance budgets per job per category
- [x] **SEL-03**: User can specify allowance type (material-only vs installed)
- [x] **SEL-04**: User can set selection deadlines per allowance
- [x] **SEL-05**: User can add selection options to a catalog (item, vendor, price, image)
- [x] **SEL-06**: User can record client selections with pricing (from catalog or custom)
- [x] **SEL-07**: User can track selection status (pending, selected, approved, ordered, installed)
- [x] **SEL-08**: User can view over/under variance per allowance (actual - budget)
- [x] **SEL-09**: User can view cumulative variance across all allowances for a job
- [x] **SEL-10**: User can create change order from allowance overage (with markup)
- [x] **SEL-11**: User can approve selections (builder confirms client choice)
- [x] **SEL-12**: User can export selections to PDF

### Scaffolded Modules

- [x] **SCF-01**: RFIs placeholder page exists with basic navigation
- [x] **SCF-02**: Submittals placeholder page exists with basic navigation
- [x] **SCF-03**: Tasks placeholder page exists with basic navigation
- [x] **SCF-04**: Messaging placeholder page exists with basic navigation
- [x] **SCF-05**: Notifications placeholder page exists with basic navigation
- [x] **SCF-06**: Warranties placeholder page exists with basic navigation
- [x] **SCF-07**: Closeout placeholder page exists with basic navigation

### Navigation

- [x] **NAV-01**: Sidebar is reorganized into logical groups (Sales, Pre-Con, Execution, Field, Finance, Admin, Comms)
- [x] **NAV-02**: New pages (Leads, Selections, scaffolds) appear in correct sidebar groups
- [x] **NAV-03**: Existing pages are moved to appropriate groups without breaking navigation

## v2 Requirements (Deferred)

### Leads/CRM Enhancements

- **LED-V2-01**: User receives dashboard alerts for overdue lead tasks

- **LED-V2-03**: User can configure automated follow-up sequences

- **SEL-V2-01**: Client-facing selection portal (view allowances, make selections)

- **SEL-V2-04**: User can import selections from vendor quotes

### Full Module Implementations

- **MOD-V2-01**: RFIs - full CRUD, assign, track, resolve
- **MOD-V2-02**: Submittals - submit, review, approve/reject workflow
- **MOD-V2-03**: Tasks - create, assign, due dates, completion tracking
- **MOD-V2-04**: Messaging - in-app threads, notifications
- **MOD-V2-05**: Notifications - centralized inbox, email digest, preferences
- **MOD-V2-06**: Warranties - product tracking, dates, claims
- **MOD-V2-07**: Closeout - certificates, manuals, handover checklist
