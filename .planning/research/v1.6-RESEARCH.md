**Created:** 2026-01-18

## Executive Summary

This research covers the two fully-built modules planned for v1.6:
1. **Leads/CRM** - Pipeline stages, lead capture, qualification, follow-ups, job conversion
2. **Selections/Allowances** - Categories, budgets, client choices, over/under tracking, change orders

Key findings:
- Custom home builder CRMs use 7-stage pipelines (Inquiry → Won/Lost)
- Qualification scoring (BANT framework) helps prioritize leads
- Selection categories are standardized across the industry (13 common categories)
- Allowance variance tracking with automatic change order generation is essential
- Client-facing portals drive adoption of selection features

## 1. Leads/CRM Features

### 1.1 Lead Pipeline Stages

**Recommended 7-Stage Pipeline for Custom Home Builders:**

| Stage | Description | Typical Duration | Key Actions |
|-------|-------------|------------------|-------------|
| **Inquiry** | Initial contact from any source | 0-24 hours | Capture contact info, log source, auto-respond |
| **Qualification** | Assess fit (budget, timeline, scope) | 1-3 days | Discovery call, qualification checklist |
| **Consultation** | In-depth discussion, site visit | 1-2 weeks | Site visit, style discussion, preliminary estimate |
| **Design Agreement** | Paid concept design phase | 2-4 weeks | Design deposit, preliminary plans & estimate |
| **Proposal** | Formal proposal presentation | 1-2 weeks | Present detailed proposal, handle objections |
| **Contract** | Final negotiation and signing | 1-2 weeks | Contract review, deposit collection |
| **Won/Lost** | Terminal stage | - | Convert to Job OR record lost reason |

**Stage Details:**

- **Inquiry**: Auto-capture from website, phone, referrals. Response time critical.
- **Qualification**: Use 5-minute checklist. Move unqualified to "Nurture" track.
- **Consultation**: On-site meeting. Take photos, discuss style, provide ballpark.
- **Design Agreement**: Separates serious buyers. Typically $3,000-$15,000.
- **Proposal**: Present in person, not via email.
- **Contract**: Include change order process. Collect initial deposit.

### 1.3 Lead Qualification

**BANT Framework for Builders:**

- **Budget**: Aligns with typical project costs? Realistic about costs/SF?
- **Authority**: Decision-maker present? Can get all decision-makers in meeting?
- **Need**: "Want" vs "need"? Scope match your specialty? In service area?
- **Timeline**: When break ground? Hard deadline? Realistic given duration?

**Qualification Scoring Model (0-15 scale):**
```
Score each criterion 0-3:
- Budget Fit:     0=way off, 1=stretch, 2=comfortable, 3=ideal
- Timeline:       0=unrealistic, 1=tight, 2=comfortable, 3=flexible
- Scope Match:    0=not our thing, 1=can do, 2=good fit, 3=perfect
- Decision Ready: 0=just browsing, 1=researching, 2=comparing, 3=ready
- Location:       0=too far, 1=edge, 2=in area, 3=ideal

Total Score:
- 12-15: Hot Lead (prioritize)
- 8-11:  Warm Lead (nurture)
- 4-7:   Cool Lead (long-term)
- 0-3:   Not Qualified (close or refer)
```

## 2. Selections/Allowances Features

### 2.1 Selection Categories

**Standard Categories (13 common for custom homes):**

| Category | Typical Subcategories | Selection Timing |
|----------|----------------------|------------------|
| **Exterior** | Brick, stone, siding, roofing, windows, doors | Early (before framing) |
| **Cabinets** | Kitchen, bath vanities, laundry, pantry, hardware | Early (8-12 week lead) |
| **Countertops** | Kitchen, bath, laundry, edge profiles | Mid (after cabinets) |
| **Flooring** | Hardwood, tile, carpet, LVP, transitions | Mid |
| **Tile** | Shower, backsplash, floor tile, accent tile | Mid |
| **Plumbing Fixtures** | Faucets, sinks, toilets, shower systems, tubs | Mid |
| **Lighting** | Chandeliers, pendants, recessed, fans, exterior | Mid-Late |
| **Appliances** | Range, refrigerator, dishwasher, hood, washer/dryer | Mid |
| **Paint Colors** | Interior walls, exterior, trim, accent walls | Late |
| **Hardware** | Door knobs, cabinet pulls, hinges | Late |
| **Electrical** | Outlet locations, switches, smart home | Early-Mid |
| **Windows & Doors** | Entry doors, interior doors, window styles | Early |
| **Roofing** | Shingles, metal, tile, color | Early |

**Organization Approaches:**
- **By Room**: Master Bath, Kitchen, Living Room (client-facing)
- **By Trade**: Electrical, Plumbing, Flooring (contractor view)
- **By Phase**: Rough-in, Finish, Final (scheduling)

### 2.2 Allowance Budgets

**Two Types of Allowances:**

1. **Material Allowance** - Covers only material cost
   - Example: "$5,000 flooring allowance (material only)"
   - Labor is separate line item

2. **Installed Allowance** - Covers material + labor
   - Example: "$8,500 flooring allowance (installed)"
   - More common for fixtures and appliances

**Typical Allowance Amounts (2025-2026):**

| Category | Typical Range | Notes |
|----------|---------------|-------|
| Kitchen Cabinets | $15,000-$45,000 | Highly variable by quality |
| Appliances | $8,000-$25,000 | Package vs individual |
| Flooring (whole house) | $15,000-$35,000 | Per SF varies $3-12 |
| Light Fixtures | $3,000-$10,000 | Often underestimated |
| Plumbing Fixtures | $5,000-$15,000 | Master + secondary baths |
| Countertops | $5,000-$20,000 | Granite vs quartz vs marble |
| Tile | $3,000-$12,000 | Depends on square footage |

**Best Practices:**
1. Base allowances on real quotes (not arbitrary)
2. Specify what's included (materials? labor? tax?)
3. Include markup policy for overages
4. Set selection deadlines in contract
5. Aim for 5-8% variance max

### 2.4 Over/Under Tracking

**Calculation Logic:**

```
Variance = Actual Selection Cost - Allowance Amount

If Variance > 0 → OVERAGE (client owes more)
If Variance < 0 → UNDERAGE/CREDIT (client receives credit)
If Variance = 0 → ON BUDGET
```

**Real-Time Tracking Features:**
- Running tally across all selections
- Per-category breakdown
- Projected vs actual (before final selection)
- Visual indicators: green (under), yellow (near), red (over)

**Example Display:**

```
┌─────────────────────────────────────────────────────────────────┐
│ ALLOWANCE SUMMARY - Smith Residence                             │
├─────────────────────┬───────────┬───────────┬───────────┬───────┤
│ Category            │ Allowance │ Selected  │ Variance  │Status │
├─────────────────────┼───────────┼───────────┼───────────┼───────┤
│ Kitchen Cabinets    │ $25,000   │ $28,500   │ +$3,500   │ OVER  │
│ Flooring            │ $18,000   │ $16,200   │ -$1,800   │ UNDER │
│ Appliances          │ $12,000   │ $14,750   │ +$2,750   │ OVER  │
│ Light Fixtures      │ $5,000    │ (pending) │    --     │ --    │
├─────────────────────┼───────────┼───────────┼───────────┼───────┤
│ TOTAL (Finalized)   │ $55,000   │ $59,450   │ +$4,450   │ OVER  │
└─────────────────────┴───────────┴───────────┴───────────┴───────┘
```

### 2.5 Change Order Integration

**Overage-to-Change-Order Flow:**

1. Client selects item exceeding allowance
2. System calculates variance
3. Change order is created (can be auto-generated)
4. Builder markup applied (typically 15-25%)
5. Client reviews and approves CO electronically
6. CO updates contract total
7. CO amount can be invoiced

**Change Order Components:**
```
Original Allowance:    $5,000
Selected Item Cost:    $6,200
Overage Amount:        $1,200
Builder Markup (20%):    $240
─────────────────────────────
Change Order Total:    $1,440
```

**Underage/Credit Handling:**
- Credit applied at closeout (all underages tallied at end)
- OR credit applied per selection (immediate)
- Contract specifies whether underages include markup credit

### 2.6 Client-Facing Features

**What Clients See:**
- Pending selections requiring decisions
- Deadline reminders and overdue alerts
- Visual allowance budget tracker
- Option comparisons with images
- Previously approved selections

**Key Client Actions:**
- Browse selection options (with images)
- Compare options side-by-side
- Add custom/client-sourced selections
- Approve selections electronically
- Review and sign change orders
- View selection history
- Add notes/questions

**Client Experience Best Practices:**
1. Visual-first (large images, minimal text)
2. Mobile-friendly (clients browse from showrooms)
3. Budget visibility (real-time tracking)
4. Clear deadlines (countdown timers)
5. Easy approval (one-click with digital signature)
6. Communication (inline comments per selection)
