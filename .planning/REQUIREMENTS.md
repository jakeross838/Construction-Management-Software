# Requirements: Ross Built CMS v2.0

**Defined:** 2026-01-19
**Core Value:** Run your entire construction business from one system

## v2.0 Requirements

Requirements for v2.0 Business Operating System release. Each maps to roadmap phases.

### CRM & Contacts

- [ ] **CRM-01**: User can create contacts with roles (client, vendor, sub, architect, inspector)
- [ ] **CRM-02**: User can create company/organization records
- [ ] **CRM-03**: User can link multiple contacts to a company
- [ ] **CRM-04**: User can log communications (calls, emails, meetings) tied to contacts
- [ ] **CRM-05**: User can link communications to jobs

### Job Hub

- [ ] **HUB-01**: User can view 360° job page showing financial summary (budget, invoices, draws, P&L)
- [ ] **HUB-02**: User can view activity timeline for a job (recent actions across all modules)
- [ ] **HUB-03**: User can view status dashboard for a job (punch lists, inspections, RFIs, submittals)

### Jobs Management

- [ ] **JMGT-01**: User can assign job category (new construction, remodel, addition, commercial)
- [ ] **JMGT-02**: User can set job timeline (start date, projected end, actual end)
- [ ] **JMGT-03**: User can view contract health (remaining value, burn rate, profit)

### Contracts

- [ ] **CNTR-01**: User can upload contract documents with versioning
- [ ] **CNTR-02**: User can track contract terms (dates, amounts, parties)
- [ ] **CNTR-03**: User can track contract amendments

### Crew Scheduling

- [ ] **CREW-01**: PM can submit work requests that become schedulable items
- [ ] **CREW-02**: System auto-schedules crew based on availability
- [ ] **CREW-03**: User can view/edit crew calendar with drag-to-reschedule
- [ ] **CREW-04**: Crew can view task queue and check off completed items

### Permitting

- [ ] **PERM-01**: User can create permit applications (type, submission date, status)
- [ ] **PERM-02**: User can schedule inspections with inspector contacts
- [ ] **PERM-03**: User can upload permit documents (permits, approvals, COO)
- [ ] **PERM-04**: User can track permit status through approval workflow

### Business Planning & Reports

- [ ] **BIZ-01**: User can view job timeline tracking with contract remaining calculations
- [ ] **BIZ-02**: User can view burn rate analysis across jobs
- [ ] **BIZ-03**: User can view company-wide metrics dashboard (pipeline, capacity, health)
- [ ] **BIZ-04**: User can view profit projections across jobs

## v2.1 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Integrations

- **INT-01**: QuickBooks integration for accounting sync
- **INT-02**: Calendar integration (Google/Outlook) for scheduling
- **INT-03**: Email integration for communication logging

### Advanced Features

- **ADV-01**: Custom report builder
- **ADV-02**: Automated email notifications for permit/inspection status
- **ADV-03**: Crew mobile app for field task management

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Mobile native app | Web works on mobile, responsive design sufficient |
| Multi-company tenancy | Single company use case |
| HR/Payroll | Separate specialized system |
| Real-time collaborative editing | SSE covers live updates |
| Video/audio attachments | Photos sufficient for documentation |
