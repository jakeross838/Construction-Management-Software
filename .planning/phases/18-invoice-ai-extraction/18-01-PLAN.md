# Plan: 18-01 Two-Stage Extraction Pipeline

## Objective

Improve invoice data extraction accuracy by implementing a two-stage pipeline that separates extraction from validation. This enables cross-field validation, better confidence scoring, and higher straight-through processing rates.

**Requirement:** INV-AI-01 - User sees improved extraction accuracy for invoice amounts, dates, and vendor names via two-stage pipeline

## Current State

- Single-pass extraction in `server/ai-processor.js`
- Inline confidence scoring calculated after extraction
- No cross-field validation (amounts vs line items, dates vs ranges)
- Confidence thresholds: HIGH (0.90), MEDIUM (0.60), LOW (0.60)

## Target State

- Stage 1: Focused extraction with Claude Vision (always use image mode for layout context)
- Stage 2: Programmatic validation with cross-field checks
- New confidence thresholds: AUTO_APPROVE (0.95), HUMAN_REVIEW (0.80), REJECT (0.70)
- Validation checks: amount totals, date ranges, vendor format

### Task 3: Implement Two-Stage Pipeline

Refactor `extractInvoiceData()` and `extractFromScannedPDF()` to use two-stage approach.

**Changes to `server/ai-processor.js`:**

```javascript
async function processInvoiceTwoStage(pdfBuffer, filename) {
  // Stage 1: Raw extraction (focus on accuracy, not validation)
  const rawExtracted = await extractInvoiceRaw(pdfBuffer, filename);

  // Stage 2: Validation and enrichment
  const validated = await validateAndEnrich(rawExtracted);

  // Calculate final confidence from both stages
  const finalConfidence = calculateFinalConfidence(
    rawExtracted.extractionConfidence,
    validated.validationScore
  );

  return {
    ...validated.data,
    confidence: finalConfidence,
    validationIssues: validated.issues,
    stage1Confidence: rawExtracted.extractionConfidence,
    stage2Score: validated.validationScore
  };
}
```

**Stage 1 changes:**
- Always use vision mode for PDFs (better layout understanding)
- Simplify extraction prompt (focus on raw data, not validation)
- Remove inline confidence calculation from Claude prompt

**Stage 2 implementation:**
- Call `invoice-validator.js` for programmatic validation
- Apply safe auto-corrections
- Calculate validation score

**Acceptance criteria:**

    [/[oO](?=\d)/g, '0'],      // O → 0 when followed by digit
