# Phase 111-01: Estimate Page UI Restructure

**Objective:** Restructure the estimate page to match Buildertrend's clean, professional layout with proper toolbar hierarchy and visual polish.

**Status:** Pending
**Phase:** 111 (Estimate Page Redesign)
**Plan:** 111-01

---

## Context

The current estimate.html has the right functionality but needs UI refinement to match the reference design. The Buildertrend layout has:
- Clean header with breadcrumb and cost summary
- Two-level toolbar (main actions + secondary controls)
- Professional empty state with clear call-to-action hierarchy
- Proper spacing and visual weight

---

## Must-Have Requirements

### Truths (what must be TRUE when done)

1. Header shows job breadcrumb (JOB: [Job Name] / ESTIMATE) instead of separate job info line
2. Cost summary displays inline in header: "Builder cost $X + Profit (Y%) $Z = Total price $W"
3. Action buttons show in header: Export, Lock estimate, Send to budget, + Proposal
4. Secondary toolbar has: Proposal dashboard button, Expand all dropdown, Jump to search
5. Empty state has proper visual hierarchy: icon → title → subtitle → buttons → divider → import options
6. "Add item", "Add group", "Set profit and tax" buttons use Buildertrend blue color scheme
7. Import section shows "IMPORT FROM" label with Excel and Template buttons below
8. Page has clean spacing matching reference design

### Artifacts (files that must exist)

- `public/estimate.html` - Updated with new layout structure
- `public/css/styles.css` - Contains new estimate page styles (or inline styles)

### Key Links (code connections that must exist)

- Header breadcrumb uses job name from `window.JobSidebar.getSelectedJob()`
- Cost summary values update when estimate data loads
- All button onclick handlers connect to existing functions
- Empty state shows/hides based on estimate existence

---

## Implementation Plan

### Step 1: Restructure Header
- Change job info line to breadcrumb format: "JOB: [NAME] / ESTIMATE"
- Move cost summary into single inline format with operators (+, =)
- Reposition action buttons to align right in header
- Add proper spacing and alignment

### Step 2: Add Secondary Toolbar
- Create new toolbar row below header
- Add "≡ Proposal dashboard" button (left side)
- Add "⌄ Expand all" dropdown button
- Keep "Jump to line items or groups..." search box
- Match spacing and styling to reference

### Step 3: Refine Empty State
- Update icon size and circle background styling
- Improve text hierarchy (larger title, proper subtitle)
- Style action buttons with Buildertrend blue (#2E6BE5 or similar)
- Add "or" divider with proper styling
- Create "IMPORT FROM" section with icon buttons for Excel/Template

### Step 4: Polish Styling
- Ensure proper spacing throughout (match reference margins/padding)
- Add subtle borders and shadows where needed
- Verify button sizes and touch targets
- Test responsive behavior on different screen sizes

### Step 5: Test Functionality
- Verify sidebar job switching updates breadcrumb
- Test all button clicks (even if showing "coming soon" toasts)
- Confirm empty state shows/hides correctly
- Check cost summary calculations
