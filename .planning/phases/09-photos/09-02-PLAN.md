
2. **Initialization (DOMContentLoaded):**
   - Load jobs into filter dropdown
   - Set up event listeners
   - Set up drag-and-drop handlers
   - Load initial photos
   - Load stats

3. **API functions:**
   - `loadStats()` - GET /api/photos/stats
   - `loadPhotos()` - GET /api/photos with filters
   - `uploadPhoto(file, metadata)` - POST /api/photos (FormData)
   - `updatePhoto(id, data)` - PATCH /api/photos/:id
   - `deletePhoto(id)` - DELETE /api/photos/:id
   - `linkPhoto(photoId, entityType, entityId)` - POST /api/photos/:id/links
   - `unlinkPhoto(photoId, linkId)` - DELETE /api/photos/:id/links/:linkId

4. **Gallery rendering:**
   ```javascript
   function renderGallery() {
     const gallery = document.getElementById('photoGallery');
     const emptyState = document.getElementById('emptyState');

     if (photos.length === 0) {
       gallery.innerHTML = '';
       emptyState.style.display = 'block';
       return;
     }

     emptyState.style.display = 'none';
     gallery.innerHTML = photos.map((photo, index) => `
       <div class="photo-card" onclick="openLightbox(${index})">
         <img src="${photo.thumbnail_url || photo.file_url}" alt="${photo.caption || ''}" loading="lazy">
         <div class="photo-overlay">
           <div>${photo.caption || 'No caption'}</div>
           <div>${photo.location || ''}</div>
         </div>
       </div>
     `).join('');
   }
   ```

5. **Filter handling:**
   - `applyFilters()` - Debounced filter application
   - Event listeners on all filter inputs
   - Clear filters button

6. **Upload modal functions:**
   - `openUploadModal()` / `closeUploadModal()`
   - Drag-and-drop handlers (dragenter, dragover, dragleave, drop)
   - File input change handler
   - `processUploadQueue()` - Upload files with progress
   - Visual feedback for upload progress

7. **Edit modal functions:**
   - `openEditModal(photoId)` - Load photo data
   - `savePhotoEdit()` - PATCH with form data
   - Show/manage entity links

8. **Lightbox functions:**
   - `openLightbox(index)` - Show full photo
   - `closeLightbox()`
   - `navigateLightbox(direction)` - +1 or -1
   - Keyboard handlers (ArrowLeft, ArrowRight, Escape)
   - Display metadata in sidebar

9. **Utility functions:**
   - `formatDate(date)` - User-friendly date display
   - `getCategoryBadge(category)` - Category badge HTML
   - `debounce(fn, delay)` - For search input

**Error handling:**
- Show toast on API errors
- Validate file types before upload
- Handle network errors gracefully
