<task type="auto">
  <name>Task 1: Convert hardcoded px font sizes to rem</name>
  <files>public/css/styles.css</files>
  <action>
Find and convert hardcoded pixel font sizes:

1. Search for `font-size: 10px`, `font-size: 11px`, `font-size: 12px`, `font-size: 13px`, `font-size: 14px`
2. Convert to rem equivalents (base 16px):
   - 10px → 0.625rem
   - 11px → 0.6875rem
   - 12px → 0.75rem
   - 13px → 0.8125rem
   - 14px → 0.875rem

3. Apply conversions:

```css
/* Before */
font-size: 12px;

/* After */
font-size: 0.75rem;
```

4. Check for any other px font-size values and convert similarly
5. Do NOT change font sizes that are intentionally pixel-perfect (e.g., icon dimensions)
  </action>
  <verify>Grep for "font-size:.*px" - should find minimal occurrences (only icon-related)</verify>
  <done>Hardcoded px font sizes converted to rem</done>
</task>

<task type="auto">
  <name>Task 2: Convert keyword font-weights to numeric</name>
  <files>public/css/styles.css</files>
  <action>
Replace font-weight keywords with numeric values:

1. Find and replace:
   - `font-weight: bold` → `font-weight: 700`
   - `font-weight: normal` → `font-weight: 400`

2. Apply changes:

```css
/* Before */
font-weight: bold;
font-weight: normal;

/* After */
font-weight: 700;
font-weight: 400;
```

3. Remove any `!important` on font-weight where possible (address specificity instead)
4. Document the font-weight scale in use:
   - 400 = regular
   - 500 = medium
   - 600 = semibold (most common)
   - 700 = bold
  </action>
  <verify>Grep for "font-weight: bold" - should find 0 occurrences</verify>
  <done>Font-weight keywords converted to numeric values</done>
</task>

<task type="auto">
  <name>Task 3: Add typography CSS variables</name>
  <files>public/css/styles.css</files>
  <action>
Add CSS variables for font weights (if not already present):

1. Check :root for existing font-weight variables
2. Add if missing (at top of :root section):

```css
:root {
  /* Font weights */
  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;
}
```

3. Document typography scale in a comment:

```css
/* ================================================================
   TYPOGRAPHY SCALE
   Font sizes: 0.75rem (12px), 0.8125rem (13px), 0.875rem (14px),
               1rem (16px), 1.25rem (20px), 1.5rem (24px)
   Font weights: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
   ================================================================ */
```

4. Note: Do NOT refactor existing font-weight declarations to use variables
   (that would be too invasive for a polish pass)
  </action>
  <verify>Grep for "--font-weight-" - should find the variables defined</verify>
  <done>Typography variables documented</done>
</task>
