## What Was Built

Added PDF export endpoints to the Reports API for job cost and vendor spend reports using the pdfmake library.

### New Dependencies

| Package | Version | Purpose |
|---------|---------|---------|
| pdfmake | ^0.3.3 | PDF generation with professional table formatting |

### New Endpoints

| Endpoint | Description |
|----------|-------------|
| GET /api/reports/job-cost/:jobId/pdf | Download job cost report as PDF |
| GET /api/reports/vendor-spend/pdf | Download vendor spend report as PDF |

### PDF Features

**Page Layout:**
- Page size: Letter (8.5x11)
- Page margins: [40, 60, 40, 60]
- Header: Report name + "Page X of Y" (right-aligned)
- Footer: "Generated by Ross Built CMS - [date]" (centered)

**Job Cost Report PDF:**
- Title: "{Job Name} - Job Cost Report"
- Subtitle: Period filter or "All Time"
- Summary section: Total Budget, Committed, Actual, Variance, % Complete
- Data table columns: Cost Code | Description | Budget | Committed | Actual | Variance | Var % | Status
- Color-coded status: red (over), orange (near), green (under)
- Filename: `Job-Cost-{JobName}-{date}.pdf`

**Vendor Spend Report PDF:**
- Title: "Vendor Spend Report"
- Subtitle: Job filter + Period filter
- Summary section: Total Spend, Vendor Count, Invoice Count, Avg Invoice Amount
- Data table columns: Vendor | Invoice Count | Total Spend | Avg Invoice | Last Invoice Date
- Filename: `Vendor-Spend-{JobName|All}-{date}.pdf`

**Table Formatting:**
- Header row: Blue background (#D9E1F2), blue text (#1F4E78), bold
- Currency columns: Right-aligned with $ prefix
- `headerRows: 1` ensures headers repeat on each page
- Thin gray borders (#CCCCCC) around cells

## API Response Format

Both PDF endpoints stream the PDF file directly to the response with appropriate headers:

```
Content-Type: application/pdf
Content-Disposition: attachment; filename="Report-Name-Date.pdf"
```

The PDF is generated using pdfmake's `getBuffer()` method and sent as a Buffer to the response.

## Notes

- PDF export reuses the same data fetching logic as the JSON endpoints (consistency)
- pdfmake was chosen over Puppeteer for better table handling and faster generation
- The endpoints follow the same query parameter patterns as JSON/Excel exports
- Date range filtering supported via `startDate` and `endDate` query params
