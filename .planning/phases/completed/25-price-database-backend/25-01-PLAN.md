# Plan 25-01: Price Database API Verification

## Objective

Verify and test the existing price database backend implementation to confirm it meets PRC-01 requirements. The routes and services were implemented alongside the database migration; this plan validates the implementation.

## Context

Discovery: Phase 25 implementation already exists:
- `server/routes/price-intelligence.js` (693 lines) - Complete API routes
- `server/price-matcher.js` (599 lines) - Item matching and price normalization

This plan focuses on verification rather than implementation.

## Success Criteria

From ROADMAP.md Phase 25:
1. User can list/search master items via API
2. User can view all vendor prices for a master item
3. Prices are normalized to common units ($/each, $/lf, $/sf)
4. Confidence scores reflect data quality

## Verification Script

```javascript
// Quick verification script
const BASE = 'http://localhost:3001/api/price-intelligence';

async function verify() {
  // 1. Stats
  const stats = await fetch(`${BASE}/stats`).then(r => r.json());
  console.log('Stats:', stats);

  // 2. Master items
  const items = await fetch(`${BASE}/master-items`).then(r => r.json());
  console.log(`Master items: ${items.length}`);

  // 3. Current prices
  const prices = await fetch(`${BASE}/current-prices`).then(r => r.json());
  console.log(`Current prices: ${prices.length}`);

  // 4. Single item with prices
  if (items.length > 0) {
    const detail = await fetch(`${BASE}/master-items/${items[0].id}`).then(r => r.json());
    console.log('Item detail:', detail.standard_name, 'vendors:', detail.vendor_prices?.length);
  }

  // 5. Categories
  const cats = await fetch(`${BASE}/categories`).then(r => r.json());
  console.log(`Categories: ${cats.length}`);

  console.log('\n✓ All endpoints responding');
}

verify().catch(console.error);
```
