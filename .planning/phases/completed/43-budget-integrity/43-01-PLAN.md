  <action>
Create migration file with two PostgreSQL functions:

1. `increment_committed_amount(p_job_id UUID, p_cost_code_id UUID, p_amount DECIMAL)`:
   - Find the budget line for (job_id, cost_code_id)
   - If budget line does NOT exist, raise an exception: 'Budget line not found for job/cost_code - budget must exist before committing'
   - If it exists, atomically increment committed_amount by p_amount
   - Return the updated committed_amount

2. `decrement_committed_amount(p_job_id UUID, p_cost_code_id UUID, p_amount DECIMAL)`:
   - Find the budget line for (job_id, cost_code_id)
   - If not found, do nothing (void on non-existent budget is a no-op)
   - If found, atomically decrement committed_amount by p_amount
   - Use GREATEST(0, committed_amount - p_amount) to prevent negative values
   - Return the updated committed_amount

Use `CREATE OR REPLACE FUNCTION` with SECURITY DEFINER for Supabase RPC access.
Set search_path to prevent privilege escalation.

Include header comment explaining:
- These functions support PO approval/void workflow
- increment is called on PO approve
- decrement is called on PO void
