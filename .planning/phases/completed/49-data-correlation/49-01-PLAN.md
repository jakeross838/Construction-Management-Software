<task type="auto">
  <name>Task 1: Create linkage validation endpoint</name>
  <files>server/routes/invoices.js</files>
  <action>
Add GET /api/jobs/:jobId/validate-linkages endpoint that:

1. Queries all invoices for the job with their allocations
2. Checks for orphaned allocations:
   - Allocations with po_id pointing to non-existent or deleted PO
   - Allocations with po_line_item_id pointing to non-existent line item
   - Allocations with change_order_id pointing to non-existent CO
3. Checks for broken draw links:
   - Invoices in draws that have status other than 'approved' or 'in_draw'
   - Draw allocations that don't match invoice allocations
4. Checks for invoice linkage issues:
   - Invoices with po_id but no matching allocations
   - Invoices with allocations totaling more than invoice amount

Return format (matching Phase 48 validation pattern):
```javascript
{
  valid: boolean,
  errors: [{ type, severity: 'error', details, fix_hint }],
  warnings: [{ type, severity: 'warning', details, fix_hint }],
  summary: {
    invoices_checked: number,
    allocations_checked: number,
    errors_found: number,
    warnings_found: number
  }
}
```

Error types to implement:
- ORPHANED_PO_ALLOCATION - allocation references deleted/missing PO
- ORPHANED_LINE_ITEM_ALLOCATION - allocation references deleted/missing line item
- ORPHANED_CO_ALLOCATION - allocation references deleted/missing CO
- DRAW_STATUS_MISMATCH - invoice in draw with wrong status
- ALLOCATION_SUM_EXCEEDS_INVOICE - allocations total more than invoice amount
- INVOICE_PO_NO_ALLOCATIONS - invoice has po_id but no allocations (warning)

Place endpoint near other job-related invoice endpoints (around line 400).
Use asyncHandler wrapper for error handling.
  </action>
  <verify>curl http://localhost:3001/api/jobs/{jobId}/validate-linkages returns JSON with valid, errors, warnings, summary fields</verify>
  <done>Endpoint returns validation results identifying orphaned allocations and linkage issues</done>
</task>
