<task type="auto">
  <name>Task 1: Add normalizeStatusClass helper to app.js</name>
  <files>public/js/app.js</files>
  <action>
Add a global helper function that normalizes status values for CSS class names near the top of app.js:

```javascript
// Normalize status value for CSS class names (underscores to hyphens)
function normalizeStatusClass(status) {
  if (!status) return '';
  return status.toString().toLowerCase().replace(/_/g, '-');
}

// Make available globally for other modules
window.normalizeStatusClass = normalizeStatusClass;
```
