# Phase 66-01: Selections Schema

## Objective

Create database tables for visual catalog with multiple photos per product, product specs/dimensions, and category hierarchy.

## Requirements

- CAT-06: Product details include quantities, square footage, and specs
- MGT-03: Staff can add multiple photos per product with gallery

## Tasks

### Task 1: Add category hierarchy support
- [x] Add `parent_id` column to v2_selection_categories for multi-level navigation
- [x] Add `slug` column for URL-friendly category names
- [x] Add `image_url` column for category images
- [x] Create index for parent lookups

### Task 2: Enhance catalog item columns
- [x] Add `specs` JSONB column for product specifications (color, finish, style)
- [x] Add `dimensions` JSONB column (width, height, depth, unit)
- [x] Add `square_footage` column for area-based products

- [x] Add `room` column (Kitchen, Master Bath, etc.)
- [x] Add `tags` array column for search/filtering

- [x] Add foreign key to v2_selection_catalog

### Task 4: Create triggers for primary image management
