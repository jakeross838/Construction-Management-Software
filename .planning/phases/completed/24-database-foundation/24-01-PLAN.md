# Plan 24-01: Schema Migration

## Objective

Verify and apply the price intelligence database schema, ensuring all tables, views, functions, and seed data are properly created.

## Context

- Migration files already exist: `migration-044-price-intelligence.sql` and `migration-045-seed-price-intelligence.sql`
- These create 10 new tables, 1 materialized view, helper functions, and seed data
- Need to verify migrations are applied and working correctly

## Success Criteria

From ROADMAP.md Phase 24:
1. All v2_* tables for price intelligence exist in database
2. Materialized view v2_current_prices returns latest price per item/vendor
3. Waste factors seeded with construction category defaults
4. Vendor table has delivery/lead time columns

## Verification Script

Run this SQL to verify all components:

```sql
-- Check tables exist
SELECT table_name FROM information_schema.tables
WHERE table_schema = 'public' AND table_name LIKE 'v2_%'
ORDER BY table_name;

-- Check materialized view
SELECT COUNT(*) as price_count FROM v2_current_prices;

-- Check waste factors
SELECT COUNT(*) as factor_count FROM v2_waste_factors;

-- Check vendor columns
SELECT column_name FROM information_schema.columns
WHERE table_name = 'v2_vendors'
AND column_name IN ('delivery_fee', 'free_delivery_minimum', 'typical_lead_days');

-- Check functions
SELECT routine_name FROM information_schema.routines
WHERE routine_schema = 'public'
AND routine_name LIKE '%price%';

-- Check views
SELECT table_name FROM information_schema.views
WHERE table_schema = 'public' AND table_name LIKE 'v_%';
```
