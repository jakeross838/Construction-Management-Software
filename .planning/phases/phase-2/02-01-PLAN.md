The current implementation already sends PDFs as `type: "document"` to Claude, which means Claude Vision is already being used for PDF processing. The question is whether we need additional detection/handling for scanned vs digital PDFs.

2. Add confidence-based OCR detection (if Claude returns low confidence, might indicate scanned document)
3. Optionally add explicit text extraction check before sending to Claude (optimization)

Add a helper function to detect if extraction results suggest a scanned PDF:

```typescript
// Minimum confidence to consider extraction successful (not scanned/OCR)
const MIN_OCR_CONFIDENCE = 0.5;

/**
 * Check if extraction results indicate a scanned/OCR document
 * Based on confidence scores - low confidence across all fields suggests OCR
 */
function isLikelyScannedDocument(confidence: ExtractedInvoiceData['extractionConfidence']): boolean {
  if (!confidence) return false;

  const avgConfidence = (
    (confidence.vendor || 0) +
    (confidence.amount || 0) +
    (confidence.invoiceNumber || 0) +
    (confidence.date || 0) +
    (confidence.job || 0)
  ) / 5;

  return avgConfidence < MIN_OCR_CONFIDENCE;
}
```

Add this function before the serve() handler, around line 175.

Update the response to include `isScannedDocument` boolean based on this detection:

```typescript
// In the result object
```
