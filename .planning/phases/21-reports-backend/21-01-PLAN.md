  <name>Task 1: Create reports router with job cost report endpoint</name>

  <action>
Create new Express router file `server/routes/reports.js` with:

1. **Job Cost Report** - `GET /api/reports/job-cost/:jobId`

   Query params: `?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` (optional)

   Returns:
   ```javascript
   {
     job: { id, name },
     period: { start, end },
     summary: {
       totalBudget,
       totalCommitted,  // from POs
       totalActual,     // from approved invoices
       totalVariance,
       percentComplete
     },
     lines: [
       {
         costCode: "03100",
         description: "Concrete",
         budget: 50000,
         committed: 45000,
         actual: 42000,
         variance: 8000,
         variancePercent: 16,
         status: "under"  // "over" | "near" | "under"
       }
     ]
   }
   ```

   Implementation:
   - Query `v2_budget_lines` for budgeted amounts by job
   - Query `v2_po_line_items` joined with `v2_purchase_orders` for committed
   - Query `v2_invoice_allocations` joined with `v2_invoices` (status in approved, in_draw, paid) for actual
   - Apply date filter to invoice_date if provided
   - Group by cost_code
   - Calculate variance = budget - actual
   - Status: over (actual > budget), near (actual > 90% budget), under

Pattern to follow from existing code:
```javascript
const express = require('express');
const router = express.Router();
const { supabase } = require('../../config');
const { asyncHandler } = require('../errors');
```

Use existing patterns from server/routes/invoices.js for error handling and query structure.

<task type="auto">
  <name>Task 2: Add vendor spend and category spend endpoints</name>
  <files>server/routes/reports.js</files>
  <action>
Add two more endpoints to the reports router:

2. **Vendor Spend Report** - `GET /api/reports/vendor-spend`

   Query params: `?jobId=uuid&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` (all optional)

   Returns:
   ```javascript
   {
     period: { start, end },
     filters: { jobId, jobName },
     summary: {
       totalSpend,
       vendorCount,
       invoiceCount,
       avgInvoiceAmount
     },
     vendors: [
       {
         vendorId: "uuid",
         vendorName: "Florida Sunshine Carpentry",
         invoiceCount: 12,
         totalSpend: 45000,
         avgInvoiceAmount: 3750,
         lastInvoiceDate: "2026-01-15"
       }
     ]
   }
   ```

   Implementation:
   - Query `v2_invoices` joined with `v2_vendors`
   - Filter by status in (approved, in_draw, paid)
   - Apply jobId filter if provided
   - Apply date range to invoice_date if provided
   - GROUP BY vendor_id
   - Order by totalSpend DESC

3. **Category Spend Report** - `GET /api/reports/category-spend`

   Query params: `?jobId=uuid&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` (all optional)

   Returns:
   ```javascript
   {
     period: { start, end },
     filters: { jobId, jobName },
     summary: {
       totalSpend,
       categoryCount
     },
     categories: [
       {
         categoryCode: "03",
         categoryName: "Concrete",
         costCodeCount: 5,
         totalSpend: 125000,
         percentOfTotal: 18.5
       }
     ]
   }
   ```

   Implementation:
   - Query `v2_invoice_allocations` joined with `v2_cost_codes` and `v2_invoices`
   - Filter invoices by status in (approved, in_draw, paid)
   - Apply jobId and date filters if provided
   - Extract category from first 2 digits of cost_code
   - GROUP BY category code
   - Calculate percentOfTotal for each category
   - Order by totalSpend DESC

Use consistent date parsing pattern:
```javascript
const startDate = req.query.startDate || null;
const endDate = req.query.endDate || null;

let query = supabase.from('v2_invoices')...;
if (startDate) query = query.gte('invoice_date', startDate);
if (endDate) query = query.lte('invoice_date', endDate);
```
