# Phase 112-02: Hierarchy Database Schema

## Objective
Add database schema to support 3-level hierarchy (Groups > Subgroups > Items) for estimate organization.

## Context
@database/schema.sql
@.planning/phases/112-fix-estimates-functionality/112-01-PLAN.md

User needs to organize estimates as:
- **Groups** (e.g., MEPs, Framing) - top level
- **Subgroups** (e.g., Electrical, Plumbing) - within groups
- **Items** (line items) - within subgroups

Current schema has `v4_estimate_sections` (unused) and flat `v4_estimate_lines`.

## Tasks

### Task 1: Create Migration for Subgroups and Hierarchy

Create `database/migration-012-estimate-hierarchy.sql`:

```sql
-- Rename sections to groups (more intuitive)
ALTER TABLE v4_estimate_sections RENAME TO v4_estimate_groups;

-- Add sort_order to groups
ALTER TABLE v4_estimate_groups ADD COLUMN IF NOT EXISTS sort_order INTEGER DEFAULT 0;

-- Create subgroups table
CREATE TABLE IF NOT EXISTS v4_estimate_subgroups (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  estimate_id UUID NOT NULL REFERENCES v4_estimates(id) ON DELETE CASCADE,
  group_id UUID NOT NULL REFERENCES v4_estimate_groups(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Add subgroup_id and sort_order to line items
ALTER TABLE v4_estimate_lines ADD COLUMN IF NOT EXISTS subgroup_id UUID REFERENCES v4_estimate_subgroups(id) ON DELETE SET NULL;
ALTER TABLE v4_estimate_lines ADD COLUMN IF NOT EXISTS sort_order INTEGER DEFAULT 0;

-- Rename section_id to group_id for clarity
DO $$
BEGIN
  IF EXISTS (
    SELECT 1 FROM information_schema.columns
    WHERE table_name = 'v4_estimate_lines'
    AND column_name = 'section_id'
  ) THEN
    ALTER TABLE v4_estimate_lines RENAME COLUMN section_id TO group_id;
  END IF;
END $$;

-- Create indexes for performance
CREATE INDEX IF NOT EXISTS idx_groups_estimate ON v4_estimate_groups(estimate_id, sort_order);
CREATE INDEX IF NOT EXISTS idx_subgroups_group ON v4_estimate_subgroups(group_id, sort_order);
CREATE INDEX IF NOT EXISTS idx_lines_subgroup ON v4_estimate_lines(subgroup_id, sort_order);
CREATE INDEX IF NOT EXISTS idx_lines_group ON v4_estimate_lines(group_id, sort_order);
```

**Verification:**
- Run migration: `npm run migrate`
- Check tables exist: `v4_estimate_groups`, `v4_estimate_subgroups`
- Check columns: `v4_estimate_lines.subgroup_id`, `v4_estimate_lines.sort_order`
- Check indexes exist
