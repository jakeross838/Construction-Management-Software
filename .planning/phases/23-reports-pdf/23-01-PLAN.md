<task type="auto">
  <name>Task 1: Install pdfmake and add PDF export for Job Cost Report</name>
  <files>package.json, server/routes/reports.js</files>
  <action>
1. **Install pdfmake** (if not already installed):
   ```bash
   npm install pdfmake
   ```

2. **Add pdfmake import** at top of reports.js:
   ```javascript
   const pdfMake = require('pdfmake/build/pdfmake');
   const pdfFonts = require('pdfmake/build/vfs_fonts');
   pdfMake.vfs = pdfFonts.pdfMake.vfs;
   ```

3. **Add new endpoint** `GET /api/reports/job-cost/:jobId/pdf` that:

   - **Reuses existing data logic** from the `/job-cost/:jobId` endpoint (same data fetching)

   - **Creates a pdfmake document definition** with:
     - Page size: Letter (8.5x11)
     - Page margins: [40, 60, 40, 60]
     - Header function showing "Job Cost Report - Page X of Y" (right-aligned, 10pt)
     - Footer function showing "Generated by Ross Built CMS" and date (centered, 10pt)

   - **Content structure:**
     - Title: "{Job Name} - Job Cost Report" (24pt, bold, blue #1F4E78)
     - Subtitle: "Period: {startDate} to {endDate}" or "All Time" (12pt, gray)
     - Summary section with 5 rows: Total Budget, Committed, Actual, Variance, % Complete
     - Data table with columns: Cost Code | Description | Budget | Committed | Actual | Variance | Var % | Status

   - **Table formatting:**
     - Header row: Bold, blue background (#D9E1F2), blue text (#1F4E78)
     - Currency columns: Right-aligned with $ prefix
     - Status column: Color-coded text (red for "over", orange for "near", green for "under")
     - Column widths: ['10%', '25%', '12%', '12%', '12%', '12%', '9%', '8%']
     - headerRows: 1 (repeat header on each page)

   - **Response:**
     - Content-Type: `application/pdf`
     - Content-Disposition: `attachment; filename="Job-Cost-{JobName}-{date}.pdf"`
     - Stream with `pdfMake.createPdf(docDefinition).getBuffer(callback)` then pipe to response

   **Pattern from v1.3-RESEARCH.md:**
   ```javascript
   const docDefinition = {
     pageSize: 'LETTER',
     pageMargins: [40, 60, 40, 60],
     header: (currentPage, pageCount) => ({
       text: `Job Cost Report - Page ${currentPage} of ${pageCount}`,
       alignment: 'right',
       fontSize: 10,
       margin: [40, 20, 40, 0]
     }),
     footer: (currentPage, pageCount) => ({
       text: `Generated by Ross Built CMS - ${new Date().toLocaleDateString()}`,
       alignment: 'center',
       fontSize: 10,
       margin: [40, 0, 40, 20]
     }),
     content: [
       { text: jobName, style: 'title' },
       { text: periodText, style: 'subtitle' },
       // ... summary and table
     ],
     styles: {
       title: { fontSize: 24, bold: true, color: '#1F4E78' },
       subtitle: { fontSize: 12, color: '#666666', margin: [0, 0, 0, 20] },
       tableHeader: { bold: true, fillColor: '#D9E1F2', color: '#1F4E78' }
     }
   };

   const pdfDoc = pdfMake.createPdf(docDefinition);
   pdfDoc.getBuffer((buffer) => {
     res.setHeader('Content-Type', 'application/pdf');
     res.setHeader('Content-Disposition', `attachment; filename="${filename}"`);
     res.send(Buffer.from(buffer));
   });
   ```
  </action>
  <verify>node -c server/routes/reports.js && npm ls pdfmake</verify>
  <done>GET /api/reports/job-cost/:jobId/pdf returns a properly formatted PDF file with headers, footers, and page numbers</done>
</task>
