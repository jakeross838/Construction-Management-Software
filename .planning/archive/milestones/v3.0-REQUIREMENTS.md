# Requirements: Ross Built CMS v3.0

**Defined:** 2026-01-20
**Core Value:** Run your entire construction business from one intelligent system

## v3.0 Requirements

Requirements for Smart Catalog & Estimation Engine milestone. All shipped.

### Catalog Enhancement

- [x] **CAT-ENH-01**: Catalog items have labor hours, install duration, lead time fields
- [x] **CAT-ENH-02**: Catalog items have waste factor and coverage rate
- [x] **CAT-ENH-03**: Catalog items have quality tier (builder/standard/premium)
- [x] **CAT-ENH-04**: Catalog items link to compatible trades
- [x] **CAT-ENH-05**: Catalog items have permit requirement flags
- [x] **CAT-ENH-06**: Catalog items have rough-in requirements
- [x] **CAT-ENH-07**: Catalog items have dependency relationships (before/after)
- [x] **CAT-ENH-08**: Catalog items have warranty terms

### Construction Knowledge Base

- [x] **KNOW-01**: Catalog items have installation warnings
- [x] **KNOW-02**: Catalog items have quality check lists
- [x] **KNOW-03**: Catalog items have pre-installation requirements
- [x] **KNOW-04**: Catalog items have inspection points
- [x] **KNOW-05**: Catalog items have common defect patterns
- [x] **KNOW-06**: Knowledge base feeds punch list suggestions
- [x] **KNOW-07**: Knowledge base feeds inspection checklists
- [x] **KNOW-08**: Knowledge captures and shares across similar selections

### Trade Scorecards

- [x] **TRADE-01**: Trade/vendor records with cost, quality, speed, reliability scores
- [x] **TRADE-02**: Trade capacity and availability tracking
- [x] **TRADE-03**: Trade performance updates from completed work
- [x] **TRADE-04**: Trade recommendations based on job requirements

### Document Intelligence

- [x] **DOC-INT-01**: AI parses uploaded proposals/quotes for product data
- [x] **DOC-INT-02**: Parsed data routes to catalog (new/updated products)
- [x] **DOC-INT-03**: Parsed data routes to price intelligence
- [x] **DOC-INT-04**: Parsed data routes to schedule (lead times)
- [x] **DOC-INT-05**: Parsed data flags permit requirements
- [x] **DOC-INT-06**: Parsed data captures rough-in requirements
- [x] **DOC-INT-07**: Parsed data captures warranty terms

### Estimate Builder

- [x] **EST-BLD-01**: Create estimate from catalog selections
- [x] **EST-BLD-02**: Enter house details (sqft, rooms, dimensions)
- [x] **EST-BLD-03**: Auto-calculate material quantities from dimensions
- [x] **EST-BLD-04**: Auto-calculate costs (material + labor)
- [x] **EST-BLD-05**: Fine-tune estimates with overrides
- [x] **EST-BLD-06**: Save and version estimates

### Schedule Generator

- [x] **SCHED-01**: Generate schedule from estimate selections
- [x] **SCHED-02**: Sequence trades by dependencies
- [x] **SCHED-03**: Factor lead times into schedule
- [x] **SCHED-04**: Show critical path
- [x] **SCHED-05**: Account for cure times and inspections

### Downstream Conversion

- [x] **FLOW-01**: Convert estimate to allowance budgets
- [x] **FLOW-02**: Generate scopes of work from estimate
- [x] **FLOW-03**: Create bid requests from scopes
- [x] **FLOW-04**: Convert approved bids to POs

### Feedback Loops

- [x] **FEED-01**: Invoice actuals update catalog pricing
- [x] **FEED-02**: Actual delivery dates update lead time estimates
- [x] **FEED-03**: Actual durations update install time estimates
- [x] **FEED-04**: Trade performance updates scorecards
- [x] **FEED-05**: Warranty claims flag products

## Out of Scope (v3.0)

| Feature | Reason | Status |
|---------|--------|--------|
| Lead-facing portal | Build internal tool first, validate, then expose | Deferred to v3.1 |
| AI floor plan extraction | Complex, manual entry works for v3.0 | Deferred |
| Architect/designer portal | Future lead gen channel after core is solid | Deferred |
| Calendar integrations | Not critical for estimation engine | Deferred |
| QuickBooks sync | Separate integration milestone | Deferred |
| Budget/quality/timeline optimizer | After data collection proves valuable | Deferred |
