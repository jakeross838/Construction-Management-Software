# Archived Requirements: Ross Built CMS v2.0

**Defined:** 2026-01-19
**Completed:** 2026-01-19
**Core Value:** Run your entire construction business from one system

## v2.0 Requirements (All Complete)

All 26 requirements for v2.0 Business Operating System have been implemented and verified.

### CRM & Contacts

- [x] **CRM-01**: User can create contacts with roles (client, vendor, sub, architect, inspector)
- [x] **CRM-02**: User can create company/organization records
- [x] **CRM-03**: User can link multiple contacts to a company
- [x] **CRM-04**: User can log communications (calls, emails, meetings) tied to contacts
- [x] **CRM-05**: User can link communications to jobs

### Job Hub

- [x] **HUB-01**: User can view 360° job page showing financial summary (budget, invoices, draws, P&L)
- [x] **HUB-02**: User can view activity timeline for a job (recent actions across all modules)
- [x] **HUB-03**: User can view status dashboard for a job (punch lists, inspections, RFIs, submittals)

### Jobs Management

- [x] **JMGT-01**: User can assign job category (new construction, remodel, addition, commercial)
- [x] **JMGT-02**: User can set job timeline (start date, projected end, actual end)
- [x] **JMGT-03**: User can view contract health (remaining value, burn rate, profit)

### Contracts

- [x] **CNTR-01**: User can upload contract documents with versioning
- [x] **CNTR-02**: User can track contract terms (dates, amounts, parties)
- [x] **CNTR-03**: User can track contract amendments

### Crew Scheduling

- [x] **CREW-01**: PM can submit work requests that become schedulable items
- [x] **CREW-02**: System auto-schedules crew based on availability
- [x] **CREW-03**: User can view/edit crew calendar with drag-to-reschedule
- [x] **CREW-04**: Crew can view task queue and check off completed items

### Permitting

- [x] **PERM-01**: User can create permit applications (type, submission date, status)
- [x] **PERM-02**: User can schedule inspections with inspector contacts
- [x] **PERM-03**: User can upload permit documents (permits, approvals, COO)
- [x] **PERM-04**: User can track permit status through approval workflow

### Business Planning & Reports

- [x] **BIZ-01**: User can view job timeline tracking with contract remaining calculations
- [x] **BIZ-02**: User can view burn rate analysis across jobs
- [x] **BIZ-03**: User can view company-wide metrics dashboard (pipeline, capacity, health)
- [x] **BIZ-04**: User can view profit projections across jobs

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Mobile native app | Web works on mobile, responsive design sufficient |
| Multi-company tenancy | Single company use case |
| HR/Payroll | Separate specialized system |
| Real-time collaborative editing | SSE covers live updates |
| Video/audio attachments | Photos sufficient for documentation |
