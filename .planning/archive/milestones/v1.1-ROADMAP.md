# Milestone v1.1: Field Features

**Status:** ✅ SHIPPED 2026-01-17
**Phases:** 7-11
**Total Plans:** 8

## Overview

Complete the placeholder features to enable full field use: vendor bid collection, cost estimation, project photo documentation, dashboard alerts, and mobile responsiveness.

## Phases

### Phase 7: Bids
**Goal**: Users can collect vendor bids, compare them, and convert to POs
**Requirements**: BID-01, BID-02, BID-03, BID-04, BID-05
**Plans**: 2 plans

Plans:
- [x] 07-01: Database schema and API routes
- [x] 07-02: Frontend page and modals

**Details:**
- `v2_bids` table with status workflow (received → under_review → accepted/rejected)
- `v2_bid_documents` for uploaded PDFs
- Full CRUD API with document management
- Side-by-side bid comparison with price highlighting
- Convert accepted bid to PO with source linking

---

### Phase 8: Estimates
**Goal**: Users can create cost estimates and convert to budgets
**Depends on**: Phase 7 (import from bids)
**Requirements**: EST-01, EST-02, EST-03, EST-04, EST-05
**Plans**: 1 plan

Plans:
- [x] 08-01: Database schema, API routes, and frontend (discovered pre-implemented)

**Details:**
- `v2_estimates` and `v2_estimate_lines` tables with versioning
- Full CRUD with line item management
- Import amounts from accepted bids
- Version control with comparison
- Convert approved estimate to budget

---

### Phase 9: Photos
**Goal**: Users can document project progress with photos
**Requirements**: PHO-01, PHO-02, PHO-03, PHO-04
**Plans**: 2 plans

Plans:
- [x] 09-01: Database schema and API routes
- [x] 09-02: Frontend gallery and upload UI

**Details:**
