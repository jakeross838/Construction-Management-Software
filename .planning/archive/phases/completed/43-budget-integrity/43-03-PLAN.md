Fix draws.js to NOT create budget lines with budgeted_amount=0 when allocating invoices.

Purpose: When an invoice is allocated to a cost code that has no budget line, draws.js currently creates a budget line with budgeted_amount=0 (lines 573-583). This hides budget planning problems. Instead, we should require that budget lines exist before invoicing.

Output: Updated draws.js that throws an error (or logs warning) when trying to update a non-existent budget line.

Current problematic code in draws.js (lines 556-586):
```javascript
// Update budget billed_amount for each allocation
if (inv.job_id && inv.allocations && inv.allocations.length > 0) {
  for (const alloc of inv.allocations) {
    if (!alloc.cost_code_id) continue;

    const { data: budgetLine } = await supabase
      .from('v2_budget_lines')
      .select('id, billed_amount')
      .eq('job_id', inv.job_id)
      .eq('cost_code_id', alloc.cost_code_id)
      .single();

    if (budgetLine) {
      const newBilled = (parseFloat(budgetLine.billed_amount) || 0) + parseFloat(alloc.amount);
      await supabase
        .from('v2_budget_lines')
        .update({ billed_amount: newBilled })
        .eq('id', budgetLine.id);
    } else {
      // BUG: Creates budget line with 0 budgeted_amount
      await supabase
        .from('v2_budget_lines')
        .insert({
          job_id: inv.job_id,
          cost_code_id: alloc.cost_code_id,
          budgeted_amount: 0,  // <-- THIS IS THE PROBLEM
          committed_amount: 0,
          billed_amount: parseFloat(alloc.amount) || 0,
          paid_amount: 0
        });
    }
  }
}
```

The same pattern appears in the remove-invoice route (lines 645-665) for decrementing.
