<task type="auto">
  <name>Task 1: Add Excel export for Job Cost Report</name>
  <files>server/routes/reports.js</files>
  <action>
Add a new endpoint `GET /api/reports/job-cost/:jobId/excel` that:

1. **Reuses the existing job cost data logic** - Extract the data fetching code from the existing `/job-cost/:jobId` endpoint into a shared helper function, OR call the existing logic inline

2. **Creates an ExcelJS workbook** with professional formatting:
   ```javascript
   const ExcelJS = require('exceljs');
   // Add at top of file with other imports
   ```

3. **Sheet structure:**
   - Title row: "Job Cost Report - {Job Name}" (merged cells, bold, large font)
   - Period row: "Period: {startDate} to {endDate}" (or "All Time" if no dates)
   - Summary section: Total Budget, Total Committed, Total Actual, Variance, % Complete
   - Blank row
   - Data table with columns: Cost Code | Description | Category | Budget | Committed | Actual | Variance | Var % | Status

4. **Formatting:**
   - Header row: Blue background (#4472C4), white bold text
   - Currency columns (Budget, Committed, Actual, Variance): `$#,##0.00` format
   - Percentage column: `0%` format
   - Status column: Conditional fill - red (#FFCCCC) for "over", yellow (#FFFFCC) for "near", green (#CCFFCC) for "under"
   - Auto-fit column widths
   - Freeze header row

5. **Response:**
   - Content-Type: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
   - Content-Disposition: `attachment; filename="Job-Cost-{JobName}-{date}.xlsx"`
   - Stream with `workbook.xlsx.write(res)`

Pattern to follow from server/index.js line ~8810:
```javascript
const workbook = new ExcelJS.Workbook();
workbook.creator = 'Ross Built CMS';
workbook.created = new Date();
const sheet = workbook.addWorksheet('Job Cost Report');
// ... add data ...
res.setHeader('Content-Type', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
res.setHeader('Content-Disposition', `attachment; filename="..."`);
await workbook.xlsx.write(res);
res.end();
```
  </action>
  <verify>node -c server/routes/reports.js</verify>
  <done>GET /api/reports/job-cost/:jobId/excel returns a properly formatted Excel file</done>
</task>
