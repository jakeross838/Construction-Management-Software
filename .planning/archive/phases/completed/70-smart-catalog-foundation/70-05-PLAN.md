<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: Verify Smart Catalog end-to-end workflow</name>
  <what-built>
Complete Smart Catalog Foundation:
- Database schema with estimation, coverage, quality, permit, warranty, trades, and dependencies
- API endpoints for all CRUD operations
- UI for viewing and editing all fields
- Trades and dependencies management
  </what-built>
  <how-to-verify>
**Prerequisites:**
1. Start the server: `npm run dev` or `npm start`
2. Open browser to http://localhost:3001/catalog.html
3. Ensure migration-082 has been applied

**Test 1: Create a new catalog item with estimation data**
1. Click "Add Product"
2. Fill in required fields (name, category, price)
3. Scroll to "Estimation & Labor" section:
   - Enter Labor Hours: 2.5
   - Enter Install Duration: 3
   - Set Crew Size: 2
   - Enter Lead Time: 7 days
4. Scroll to "Material Coverage" section:
   - Enter Waste Factor: 10 (%)
   - Enter Coverage Rate: 20
   - Select Coverage Unit: Square Feet
5. In "Quality Tier" section:
   - Select "Premium"
6. In "Permit Requirements" section:
   - Check "Requires Permit"
   - Select Permit Type: Electrical
   - Check "Rough-In Required"
   - Enter Rough-In Notes: "Requires 20A dedicated circuit"
7. In "Warranty" section:
   - Enter Warranty: 60 (months)
   - Enter Notes: "Manufacturer limited warranty"
8. Click "Save Product"

**Expected Result:** Product saves successfully, toast shows "Product created"

**Test 2: Verify data displays in product detail**
1. Click on the product you just created to open detail modal
2. Verify these sections display with correct data:
   - Estimation & Labor: 2.5 hrs labor, 3 hrs duration, 2 people, 7 days lead
   - Material Coverage: 10% waste, 20 sqft per unit
   - Quality Tier: Premium badge (orange)
   - Permit Requirements: Red "Permit Required: Electrical" badge, orange "Rough-In Required" badge, notes displayed
   - Warranty: "5 years warranty" with green shield icon

**Expected Result:** All data displays correctly in detail modal

**Test 3: Edit estimation data**
1. In the product detail modal, click "Edit"
2. Change Labor Hours to 4
3. Change Quality Tier to "Standard"
4. Uncheck "Rough-In Required"
5. Click "Save Product"
6. Close and reopen the product detail

**Expected Result:** Changes persist - shows 4 hrs labor, Standard badge (blue), no rough-in badge

**Test 4: Add trades to product (requires product ID saved)**
1. Open product for edit
2. Scroll to "Compatible Trades" section
3. Select "Plumbing" from dropdown
4. In the options that appear:
   - Enter Labor Hours override: 3
   - Enter Hourly Rate override: 85
   - Check "Primary Trade"
5. Click "Add Trade"
6. Add another trade: "Electrical" (no overrides, not primary)

**Expected Result:** Both trades appear in the linked trades list, Plumbing shows Primary badge

**Test 5: Add dependencies**
1. Still in edit mode, scroll to "Installation Dependencies"
2. Select Type: "This must be installed AFTER..."
3. Target Type: Category
4. Select Category: "Cabinets"
5. Set Gap Days: 1
6. Enter Notes: "Wait for cabinets to be installed first"
7. Click "Add Dependency"

**Expected Result:** Dependency appears in list showing "Must be AFTER Cabinets (1 day gap)"

**Test 6: Verify trades and dependencies in detail view**
1. Close the form modal
2. Open the product detail modal
3. Verify "Compatible Trades" section shows:
   - Plumbing (Primary): 3 hrs @ $85/hr = $255
   - Electrical
4. Verify "Installation Dependencies" section shows:
   - Must be installed AFTER Cabinets (1 day gap)
   - Notes visible

**Test 7: Remove trades and dependencies**
1. Open product for edit
2. Remove the Electrical trade
3. Remove the dependency
4. Close and verify in detail view

**Expected Result:** Only Plumbing trade remains, no dependencies shown

**Test 8: API verification**
Open browser console and test API directly:
```javascript
// Get a product with all its data
fetch('/api/selections/catalog/{PRODUCT_ID}')
  .then(r => r.json())
  .then(console.log)
```

**Expected Result:** Response includes:
- labor_hours, install_duration_hours, crew_size, lead_time_days
- waste_factor_percent, coverage_rate, coverage_unit
- quality_tier
- requires_permit, permit_type, rough_in_required, rough_in_notes
- warranty_months, warranty_notes
- trades array with nested trade objects
- dependencies array with nested target objects
  </how-to-verify>
  <resume-signal>
Type "approved" if all tests pass, or describe any issues found (e.g., "Issue: Trades not saving" or "Issue: Quality tier badge wrong color")
  </resume-signal>
</task>
