<task type="auto">
  <name>Task 1: Convert hardcoded px gap values to rem</name>
  <files>public/css/styles.css</files>
  <action>
Find and convert hardcoded pixel gap values:

1. Search for and replace:
   - `gap: 2px` → `gap: 0.125rem`
   - `gap: 4px` → `gap: 0.25rem`
   - `gap: 6px` → `gap: 0.375rem`
   - `gap: 8px` → `gap: 0.5rem`
   - `gap: 12px` → `gap: 0.75rem`
   - `gap: 16px` → `gap: 1rem`
   - `gap: 24px` → `gap: 1.5rem`

2. Apply conversions for all gap declarations:

```css
/* Before */
gap: 8px;

/* After */
gap: 0.5rem;
```

3. Be careful with grid-specific gaps (row-gap, column-gap) - convert those too
4. Do NOT convert gaps in calc() expressions if they require px precision
  </action>
  <verify>Grep for "gap:.*px" - should find 0 occurrences</verify>
  <done>Gap values converted to rem</done>
</task>

<task type="auto">
  <name>Task 2: Convert common hardcoded colors to CSS variables</name>
  <files>public/css/styles.css</files>
  <action>
Convert frequently-used hardcoded colors to CSS variables:

1. Focus on colors that appear multiple times:
   - `#ffffff` or `white` → `var(--card)` or `var(--foreground)` (context-dependent)
   - `#3fb950` → `var(--success)` or `var(--accent-green)`
   - `#d97706` → `var(--warning)` or `var(--accent-orange)`
   - `#dc2626` → `var(--destructive)` or `var(--accent-red)`
   - `#2563eb` → `var(--primary)` or `var(--accent-blue)`

2. For hover state colors, keep hardcoded if no variable exists:
   - `#15803d` (dark green for success hover) - acceptable if no `--success-hover` exists
   - `#b45309` (dark amber for warning hover) - acceptable
   - `#b91c1c` (dark red for danger hover) - acceptable

3. Convert gray text colors:
   - `#6b7280` → `var(--muted-foreground)` where appropriate
   - `#374151` → `var(--foreground)` where appropriate

4. Do NOT convert:
   - Colors in SVG data URIs (leave as-is)
   - Highly specific one-off colors
   - Colors that are intentionally different from the design system
  </action>
  <verify>Grep for common hex colors like "#3fb950" - should be significantly reduced</verify>
  <done>Common hardcoded colors converted to CSS variables</done>
</task>
