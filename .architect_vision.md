# Technical Architecture Specification: Phase 1.1 Mobile PWA

**Author:** Gemini (Product Architect)
**Date:** 2026-02-04
**Status:** READY FOR IMPLEMENTATION

---

## 1. Executive Summary

Phase 1.1 introduces a Progressive Web Application (PWA) for the Ross Built Construction Management Software, extending critical functionalities to mobile devices (iOS and Android). This PWA aims to empower all user roles (Field Crew, Foreman, Project Manager, Owner) with on-the-go access to essential tools, enhancing efficiency, data accuracy, and real-time decision-making. Key features include a robust GPS-tracked Time Clock, AI-powered Photo management, comprehensive Daily Logs, mobile Approvals, universal Voice Input, configurable Push Notifications, and integrated Scheduling. The PWA will feature an online-first approach with a dark theme consistent with the existing desktop application, leveraging the current React, TypeScript, Tailwind, shadcn/ui frontend stack, Node.js/Express backend, and Supabase (PostgreSQL) for data management and authentication. Quality and user privacy are paramount, with a subtle indicator for location tracking.

## 2. Database Schema (New Tables/Columns Needed)

The existing Supabase (PostgreSQL) schema will be extended to support new mobile functionalities.

### New Tables:

1.  **`v2_time_clock_entries`**
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `job_id` (UUID, FK to `v2_jobs.id`)
    *   `clock_in_time` (TIMESTAMP WITH TIME ZONE)
    *   `clock_out_time` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `clock_in_latitude` (NUMERIC, nullable)
    *   `clock_in_longitude` (NUMERIC, nullable)
    *   `clock_out_latitude` (NUMERIC, nullable)
    *   `clock_out_longitude` (NUMERIC, nullable)
    *   `current_latitude` (NUMERIC, nullable) - For real-time tracking
    *   `current_longitude` (NUMERIC, nullable) - For real-time tracking
    *   `tracking_status` (TEXT, e.g., 'active', 'paused', 'stopped')
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

2.  **`v2_time_clock_breaks`**
    *   `id` (UUID, PK)
    *   `time_clock_entry_id` (UUID, FK to `v2_time_clock_entries.id`)
    *   `break_start_time` (TIMESTAMP WITH TIME ZONE)
    *   `break_end_time` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

3.  **`v2_photos`**
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `job_id` (UUID, FK to `v2_jobs.id`, nullable)
    *   `daily_log_id` (UUID, FK to `v2_daily_logs.id`, nullable)
    *   `storage_path` (TEXT, unique) - Reference to Supabase Storage
    *   `file_name` (TEXT)
    *   `original_url` (TEXT)
    *   `thumbnail_url` (TEXT)
    *   `latitude` (NUMERIC, nullable)
    *   `longitude` (NUMERIC, nullable)
    *   `taken_at` (TIMESTAMP WITH TIME ZONE)
    *   `ai_categories` (JSONB, nullable) - AI auto-categorization
    *   `user_tags` (TEXT[], nullable)
    *   `caption` (TEXT, nullable)
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

4.  **`v2_daily_logs`** (if not exists, or extend existing)
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `job_id` (UUID, FK to `v2_jobs.id`)
    *   `log_date` (DATE)
    *   `weather_conditions` (JSONB, nullable) - e.g., { "temp": 70, "unit": "F", "condition": "sunny", "wind": "5mph" }
    *   `crew_details` (JSONB, nullable) - Array of { "user_id", "name", "hours", "trade", "notes" }
    *   `work_performed` (TEXT)
    *   `safety_notes` (TEXT, nullable)
    *   `safety_incidents` (JSONB, nullable) - Array of { "description", "severity", "action_taken" }
    *   `materials_used` (JSONB, nullable) - Array of { "item", "quantity", "unit", "cost_code" }
    *   `equipment_used` (JSONB, nullable) - Array of { "equipment", "hours" }
    *   `site_visitors` (JSONB, nullable) - Array of { "name", "company", "purpose", "time_in", "time_out" }
    *   `delays` (JSONB, nullable) - Array of { "reason", "hours_lost", "description" }
    *   `issues_reported` (TEXT, nullable)
    *   `plan_for_tomorrow` (TEXT, nullable)
    *   `submitted_at` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

5.  **`v2_push_subscriptions`**
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `endpoint` (TEXT, unique)
    *   `p256dh_key` (TEXT)
    *   `auth_key` (TEXT)
    *   `user_agent` (TEXT, nullable)
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())

6.  **`v2_notification_preferences`**
    *   `user_id` (UUID, PK, FK to `auth.users.id`)
    *   `push_enabled` (BOOLEAN, default TRUE)
    *   `email_enabled` (BOOLEAN, default TRUE)
    *   `preferences` (JSONB) - e.g., { "invoice_approved": true, "task_assigned": true, "schedule_change": true }
    *   `quiet_hours_start` (TIME, nullable)
    *   `quiet_hours_end` (TIME, nullable)
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

7.  **`v2_notifications`**
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `type` (TEXT) - e.g., 'invoice_approved', 'task_assigned', 'schedule_change'
    *   `title` (TEXT)
    *   `message` (TEXT)
    *   `entity_type` (TEXT, nullable) - e.g., 'invoice', 'task', 'schedule'
    *   `entity_id` (UUID, nullable)
    *   `read_at` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `clicked_at` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `payload` (JSONB, nullable) - Additional data for deep linking
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())

8.  **`v2_calendar_integrations`**
    *   `id` (UUID, PK)
    *   `user_id` (UUID, FK to `auth.users.id`)
    *   `provider` (TEXT) - 'google', 'apple', 'outlook'
    *   `access_token` (TEXT, encrypted)
    *   `refresh_token` (TEXT, encrypted)
    *   `token_expires_at` (TIMESTAMP WITH TIME ZONE)
    *   `calendar_id` (TEXT, nullable)
    *   `sync_enabled` (BOOLEAN, default TRUE)
    *   `last_sync_at` (TIMESTAMP WITH TIME ZONE, nullable)
    *   `created_at` (TIMESTAMP WITH TIME ZONE, default NOW())
    *   `updated_at` (TIMESTAMP WITH TIME ZONE, default NOW())

### New Columns (to existing tables):

*   **`v2_users` or `profiles`**:
    *   `role` (TEXT) - 'field_crew', 'foreman', 'project_manager', 'owner', 'admin'
    *   `default_job_id` (UUID, FK to `v2_jobs.id`, nullable)

## 3. API Endpoints (REST Contracts)

All endpoints protected by Supabase Auth with RBAC. Base path: `/api/v1/mobile/`

### Time Clock:

| Method | Endpoint | Body/Query | Response |
|--------|----------|------------|----------|
| POST | `/timeclock/clock-in` | `{ job_id, latitude, longitude }` | `{ entry: {...} }` |
| POST | `/timeclock/clock-out` | `{ entry_id, latitude, longitude }` | `{ entry: {...} }` |
| POST | `/timeclock/break/start` | `{ entry_id }` | `{ break: {...} }` |
| POST | `/timeclock/break/end` | `{ break_id }` | `{ break: {...} }` |
| GET | `/timeclock/status` | - | `{ clocked_in, entry, break }` |
| POST | `/timeclock/location` | `{ entry_id, latitude, longitude }` | `{ success: true }` |
| GET | `/timeclock/history` | `?start_date&end_date&job_id` | `{ entries: [...] }` |

### Photos:

| Method | Endpoint | Body/Query | Response |
|--------|----------|------------|----------|
| POST | `/photos/upload` | FormData: file, job_id, latitude, longitude, taken_at, tags[], caption | `{ photo: {...} }` |

| GET | `/photos/:id` | - | `{ photo: {...} }` |
| PATCH | `/photos/:id` | `{ tags, caption }` | `{ photo: {...} }` |
| DELETE | `/photos/:id` | - | `{ success: true }` |
| POST | `/photos/:id/ai-categorize` | - | `{ photo: {...}, ai_categories }` |

### Daily Logs:

## 4. Service Worker Strategy

### Caching Strategies:

| Resource Type | Strategy | Details |
|---------------|----------|---------|
| App Shell (HTML, CSS, JS) | Cache First | Instant load, update in background |
| Static Assets (images, fonts) | Cache First | Long-term cache |
| API - Reference Data (jobs, users) | Stale While Revalidate | Show cached, fetch fresh |
| API - Critical Data (approvals, status) | Network First | Fresh data priority, fallback to cache |
| User Uploads (photos) | Cache then Network | Queue offline, sync when online |

### Offline Capabilities:

```javascript
// Service Worker Registration (sw.js)
const CACHE_NAME = 'rossbuilt-pwa-v1';
const OFFLINE_QUEUE_NAME = 'offline-actions';

// Offline action types that can be queued
const QUEUEABLE_ACTIONS = [
  '/api/v1/mobile/timeclock/clock-in',
  '/api/v1/mobile/timeclock/clock-out',
  '/api/v1/mobile/photos/upload',
  '/api/v1/mobile/daily-logs'
];
```

### Push Notification Events:

| Event | Trigger | Payload |
|-------|---------|---------|
| `invoice_approved` | Invoice approval | `{ invoice_id, job_name, amount }` |
| `invoice_rejected` | Invoice rejection | `{ invoice_id, job_name, reason }` |
| `task_assigned` | New task assignment | `{ task_id, title, due_date }` |
| `schedule_change` | Schedule modification | `{ event_id, job_name, change_type }` |
| `approval_needed` | Item awaiting approval | `{ type, id, description }` |
| `timesheet_reminder` | End of day reminder | `{ message }` |
